How to operate the agent system

  1. Start the backend with python backend/server.py.
  2. Select the agent that matches your writing task.
  3. Enter your paper title/topic and choose what content to generate.
  4. Click Run Qwen to generate manuscript text.
  5. The result downloads through your browser instead of being saved on the server.
  6. Use Run Backend only when you want to generate the prompt without calling Qwen.
